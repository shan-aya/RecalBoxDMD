📶 Wi-Fi

⚠️ Ne cochez PAS cette case si votre routeur/box attribue déjà une IP fixe au DMD (réservation DHCP) -- le DHCP normal suffit dans ce cas. À activer uniquement si vous configurez l'IP manuellement.
