# Animations de démarrage / Boot animations / Animaciones de arranque

**FR** — Animations de démarrage du DMD (logo Shan_ayA par défaut + une par fête : Halloween, Noël, Nouvel An, Saint-Valentin, Pâques). Ce dossier est **géré par le projet : ne pas le modifier à la main**. Chaque fichier doit correspondre à `manifest.json` (taille et SHA-256) : un contrôle automatique (GitHub Actions) échoue sinon, et la boîte à outils comme le DMD refusent tout fichier dont l'empreinte ne correspond pas. Utilisées par le **Mode 19** de la boîte à outils (envoi par Wi-Fi à un DMD ESP32 ou Raspberry Pi) et livrées avec le démon du Raspberry Pi.

**EN** — DMD boot animations (default Shan_ayA logo + one per holiday: Halloween, Christmas, New Year, Valentine's Day, Easter). This folder is **managed by the project: do not edit it by hand**. Every file must match `manifest.json` (size and SHA-256): an automatic check (GitHub Actions) fails otherwise, and both the toolkit and the DMD reject any file whose fingerprint does not match. Used by the toolkit's **Mode 19** (Wi-Fi upload to an ESP32 or Raspberry Pi DMD) and shipped with the Raspberry Pi daemon.

**ES** — Animaciones de arranque del DMD (logotipo Shan_ayA predeterminado + una por festividad: Halloween, Navidad, Año Nuevo, San Valentín, Pascua). Esta carpeta **la gestiona el proyecto: no la modifique a mano**. Cada archivo debe coincidir con `manifest.json` (tamaño y SHA-256): una comprobación automática (GitHub Actions) falla en caso contrario, y tanto la caja de herramientas como el DMD rechazan cualquier archivo cuya huella no coincida. Las usa el **Modo 19** de la caja de herramientas (envío por Wi-Fi a un DMD ESP32 o Raspberry Pi) y se entregan con el demonio de la Raspberry Pi.

> `binaries/boot_anim/` (ancien emplacement / old location) : copie identique conservée, les firmwares ESP32 3.63 à 3.82 y téléchargent leurs animations. / Identical copy kept: ESP32 firmwares 3.63 to 3.82 download their animations from there.
