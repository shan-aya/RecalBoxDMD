## 🎯 Overview

**RecalBoxDMD Toolkit** is the Windows companion app that prepares everything a real LED marquee needs, from your existing Recalbox ROMs collection to a ready-to-use SD card — one click, even on a 30,000-game MAME fullset.

### 🔥 The problem it solves

A naive firmware reading PNG/GIF files straight off the SD card chokes on big collections:

```
❌ Without this toolkit:
   - ESP32 opens /systems/mame/ (30,000+ files) → freezes for seconds
   - PNG/GIF decoding on the ESP32 itself → slow, memory-hungry
   - Between games: black screen or visible lag
```

The toolkit pre-converts everything on your PC into a format the ESP32 can display **without decoding anything**:

```
✅ With this toolkit:
   1. PNG → .raw565 (8,192 bytes, ready to blit)
   2. GIF → .raw565pack (concatenated frames) + .meta (timings)
   3. ESP32 reads the file and sends it straight to the panel
   4. No decoding, no lag: 5–15 ms per display
```

| Metric | Without conversion | With RecalBoxDMD Toolkit |
|--------|--------------------|---------------------------|
| Display time | 500 ms – 3 s+ | **5–15 ms** |
| RAM needed on the ESP32 | 50–100 KB | **8 KB** |
| MAME fullset (30,000 games) | freezes 5–10 s | **no freeze, no black screen** |
| Setup | manual, file by file | **one "Start" click** |

### The mask system, in short

Very large systems (MAME, FBNeo...) are flagged **"L"** by the toolkit. When the firmware receives one of these games, it shows the cached system default **instantly** while the real image decodes in the background — the panel never goes black, even scrolling fast through a huge collection. Full detail in [The raw565 Format in Detail](#-the-raw565-format-in-detail).

### 🔄 How everything fits together

```
┌─────────────────────────────────────────────────────────────┐
│                          RECALBOX                            │
│   Launches a game → marquee[...].sh sends "mame/kof98"       │
│                          via UDP                              │
└──────────────────────────────┬────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                  ESP32 + HUB75 LED Panel 128×32               │
│                                                                 │
│  Receives "mame/kof98":                                        │
│   1. /systems/mame/kof98.raw565 (or .raw565pack) → instant     │
│   2. not found? look up games_cache.bin (bigram index)         │
│   3. still not found? show /systems/_defaults/mame.raw565      │
│   4. still not found? show /systems/_defaults/default.raw565   │
│                                                                 │
│   ⏱️ 5–15 ms total, whatever the size of the collection         │
└─────────────────────────────────────────────────────────────┘

           ┌───────────────────────────────────────────────┐
           │   RecalBoxDMD Toolkit (this app) — prepares the SD  │
           │  Extracts marquees from gamelist.xml             │
           │  PNG → .raw565   /   GIF → .raw565pack + .meta   │
           │  Builds the bigram game cache                    │
           │  Flags slow systems ("L") for the mask system    │
           │  Downloads free assets (_defaults + 600 GIFs)    │
           │  Installs the Recalbox userscripts (Mode 9)      │
           │  Copies everything to the SD card (resumable)    │
           └───────────────────────────────────────────────┘
```

## 🚀 Quick Start

Grab whichever build you prefer from the **[Releases page](https://github.com/shan-aya/RecalBoxDMD/releases)** (the built `.exe`/`.msi` files aren't committed to the repository itself, only released there):

**Option A — Windows installer (recommended)**
```
1. Download RecalBoxDMD_Toolkit_Setup.exe from the Releases page
2. Run it — Start Menu shortcut, optional desktop icon, proper uninstaller
3. Launch "RecalBoxDMD Toolkit" from the Start Menu
```

**Option B — Portable .exe (no install)**
```
1. Download RecalBoxDMD-<build>-portable.exe from the Releases page
2. Run it directly — no install, no Python required, single file
```

**Option C — .msi (for scripted/group-policy deployment)**
```
1. Download the .msi from the Releases page
2. msiexec /i "RecalBoxDMD Toolkit-<version>-win64.msi"   (or double-click)
```

**Option D — From Python source**
```
1. Grab the tools/ folder
2. Double-click install_and_run.bat — installs Python (via winget, if
   missing), Pillow and Markdown, then launches the GUI
   (or manually: pip install Pillow Markdown && python run_gui.py)
```

## 🖥️ Graphical Interface (GUI)

The GUI launches straight into **6 tabs**: **Main · Playlist · Advanced · Logs · Settings · Help**.

### 📌 Main Tab

Contains **Mode 1** — the one most people need. Point it at your ROMs folder and click **Start**; everything else is automatic.

Before the pipeline starts, Mode 1 walks you through two optional pre-flight steps:

- **DMD WiFi setup** — pick your 2.4 GHz network from a live scan, type the password, and the toolkit *actually verifies it* (briefly connects your PC to that network) before writing it to the SD card. This lets the DMD join your WiFi on its very first boot, skipping its fallback access-point screen entirely. Skippable — without it, the DMD falls back to its own first-boot WiFi setup page instead.
- **Fixed IP (advanced, optional, unchecked by default)** — lets the DMD use a static IP instead of a normal DHCP-assigned one. A warning is shown: use **either** a DHCP reservation on your router **or** a fixed IP here, **never both at once** — combining them can cause real connectivity problems. If you check this, the gateway/subnet/DNS fields are pre-filled from this PC's own network settings as a starting point (still worth double-checking).

Then comes the **Recalbox version** panel (10.x / 9.x / legacy — see [Recalbox Scraping Tutorial](#-recalbox-scraping-tutorial)), your **ROMs folder**, and **Start**.

Once a run finishes, a button blinks in this tab offering a **direct copy to a detected removable drive** — the copy survives an interruption (unplug/crash) and can retry only the files that failed.

### 🎬 Playlist Tab

Build your own attract-mode / idle GIF rotations: mix any combination of the bundled **600-GIF pack** (Mode 11, one click to download) and your **own GIFs** (drag a PC folder in), name the playlist, and it's ready to select as the active one. Works straight off an already-prepared SD card, or **mid-Mode-1**, off the working folder before it's even copied to the card.

### 🔬 Advanced Tab

Groups every individual operation into 5 categories, for when you don't want to run the full Mode 1 pipeline — see the [Mode Reference](#-mode-reference) table below for what each one does:

```
📥 GitHub     — Mode 2 (_defaults), Mode 11 (600-GIF pack)
🗂️ Gamelist   — Mode 3 (extraction only), Mode 8 (missing-images check)
🖼️ Images     — Mode 4 (raw565 conversion), Mode 5 (128×32 resize), Mode 10 (fallback image)
🧮 Caches     — Mode 6 (games cache), Mode 7 (systems cache)
📜 Scripts    — Mode 9 (install Recalbox userscripts)
```

Mode 3 and Mode 8 also show the **Recalbox version** panel (same selector as Mode 1), since both work from `gamelist.xml`.

### 📝 Logs Tab

Shows all script output in real time. Control buttons while a mode is running:

- **⏸️ Pause** / **▶️ Resume** — pause and resume processing
- **⏭️ Skip** — skip to the next step
- **⏹️ Stop** — stop the script

### ⚙️ Settings Tab

- Interface language: 🇫🇷 French · 🇬🇧 English · 🇪🇸 Spanish
- Visual theme (9 skins: SNES, Mega Drive, Dreamcast, PlayStation, N64, Neo Geo, Game Boy, Atari 2600, or Random)
- Default **Recalbox version** (10.x / 9.x / legacy) — the same shared value used everywhere else (Mode 1/3/8); changing it here or in any of those modes updates it everywhere and saves it to `RecalBoxDMD_prefs.json`
- Slow-system threshold (files above which a system gets flagged **"L"**, default **5,000**) — raise it if your SD card is fast enough not to need the mask system as early

### 📖 Help Tab

You're reading it — this page is rendered directly from this file.

## 🎨 Recalbox Scraping Tutorial

For the panel to display the right artwork, first **scrape** your ROMs in Recalbox with the Scraper tab set up correctly **for your version**. The Main/Advanced tabs' **"How to scrape?"** button shows annotated screenshots for this; summarized here:

### Recalbox 10.x (dedicated logo field)

1. Set **"SELECT LOGO TYPE"** to **"CLEAR"**
2. Do NOT set that same value on **"Select image type"** — that field is for the main visual (screenshot, box art...), not the logo
3. Run the scrape

Stored in `media/wheels/`, referenced by the `<logo>` tag. → choose the **10.x** profile.

### Recalbox 9.x (no dedicated logo field)

1. Set **"Select thumbnail type"** to **"MARQUEE"**
2. Do NOT set **"Select image type"** to that same value
3. Run the scrape

Stored in `media/thumbnails/`, referenced by the `<thumbnail>` tag. → choose the **9.x** profile (recommended).

### "legacy" profile

If your setup scrapes the logo/marquee via **"Select image type"** (set to **"Clear Logo"** or **"Marquee"**), files land in `media/images/`, referenced by the `<image>` tag. → choose the **legacy** profile.

> **💡 Tips**: Screenscraper.fr or TheGamesDB give the best results. Already scraped with a different config? Use **"Clean folders before scraping"** first. Not sure what you actually got? Run **Mode 8**.

## 🔧 DMD Panel Assembly

The hardware build (2 panels + DMDos Board + ESP32 + microSD) is quick and needs no soldering:

1. **Join the two panels** with the union pieces that ship with the DMDos Board (any M3 screw works).
2. **Seat the DMDos Board** on the **input** connector (not output) — keep the back-panel orientation identical on both halves.
3. **Wire the power** (red/black per the silkscreen) *before* placing the ESP32 on top, and connect the two panels with the included ribbon cable.
4. **Insert the SD card** you prepared with this toolkit, plug in the flashed ESP32, power everything through the USB‑C port.

> ⚠️ The **DMDos** website ([dmdos.net](https://www.dmdos.net/)) offers its own separate firmware. Only reuse its **hardware and assembly guide** — the firmware and SD card content must come from this toolkit, not from DMDos.

Full illustrated guide with photos: [dmdos.net → Montaje/Assembly](https://www.dmdos.net/#montaje). 3D-printable frame by Janibol ([Retromojones](https://www.youtube.com/@retromojones)) on [Thingiverse](https://www.thingiverse.com/thing:6704880).

## ⚡ ESP32 Firmware

### 🔧 Compiling from source

1. Open `RecalBox_DMD.ino` in the **Arduino IDE**.
2. Install these libraries (Sketch → Include Library → Manage Libraries):

| Library | Purpose |
|---------|---------|
| ESP32-HUB75-MatrixPanel-I2S-DMA | DMA LED panel driving |
| AnimatedGIF | GIF decoding (fallback path) |
| pngle | PNG decoding (fallback path, bundled) |
| WiFiManager | WiFi configuration |
| Adafruit GFX Library | Text/shape rendering |
| PubSubClient | MQTT (kept dormant — UDP is the default transport) |
| ArduinoJson | Config & web page (de)serialization |

3. Tools → Board: **ESP32 Dev Module**, Flash size **4 MB**, Partition Scheme **Huge APP**.
4. Select the correct COM port, then **Upload**.

### ⚙️ Configuration (config.ini)

You never need to hand-write this file — Mode 1 writes it for you, and the DMD's own web page lets you edit every value live afterwards. For reference:

```ini
# Display
brightness=40                 # panel brightness 0-100 %

# Playlist
playlist=RecalBox_intros.txt  # played from /playlist
random=1                      # 0 = sequential, 1 = random

# Wi-Fi
wifi_enabled=1
wifi_ssid=mywifi
wifi_password=mypassword
wifi_static_enabled=1         # 1 = use the fixed-IP fields below instead of DHCP
wifi_static_ip=192.168.1.240
wifi_gateway=192.168.1.1
wifi_subnet=255.255.255.0

# Recalbox link (UDP)
recalbox_ip=192.168.1.104     # fixed IP of your Recalbox

# Clock (retro clock themes)
[CLOCK]
CLOCK_ENABLED=1
CLOCK_THEME=-1                # -1=random, 0=Mario ... 9=Level 1-1
CLOCK_INTERVAL=5              # number of GIFs before showing the clock
CLOCK_DURATION=60             # seconds the clock stays on screen
```

### 🌐 Web Installer

> [👉 Install from the browser-based Web Installer](https://shan-aya.github.io/RecalBoxDMD/)

Chrome or Edge, plug the ESP32 in via USB, click **Install**, pick the COM port — about a minute, no Arduino IDE. Tick **"Erase device"** on a first install, or when coming from another firmware.

### 📡 UDP link & Telnet

```
Recalbox → marquee[...].sh → UDP → ESP32 → LED panel

1. You launch "King of Fighters '98"
2. The bash userscript detects the event → sends "mame/kof98"
3. ESP32 looks up, in order:
   a. /systems/mame/kof98.raw565 (or .raw565pack)   ← instant
   b. games_cache.bin bigram index                   ← accelerated
   c. /systems/_defaults/mame.raw565                 ← system fallback
   d. /systems/_defaults/default.raw565               ← global fallback
4. Displayed in under 15 ms
```

Install the userscript with **Mode 9**, or copy `marquee[...].sh` manually to `/recalbox/share/userscripts/`.

**Manual control from the Recalbox menu** — Mode 9 also installs scripts you can trigger by hand (**START → Advanced Settings → User Scripts**): WiFi Recovery DMD (back into recovery AP mode), Config Web DMD (opens the web config page), Reboot DMD, and brightness ±10%.

A **Telnet** console is built in for on-device debugging: `telnet <esp32-ip>` then `help`.

## 🏆 In-Game Overlays — Hi-Score, Game Info, Achievements & RB Challenge

While a game is actually running (never during idle/playlist mode), the panel can automatically alternate the marquee with up to **four** community-driven overlays — always self-limited, reverting to the marquee on a timer that lives entirely on the DMD itself:

- 🏆 **Hi-Score (MAME/FBNeo)** — decodes the emulator's own saved score file against a community manifest (thousands of games covered) and shows the real top rankings.
- ℹ️ **Game Info** — description, genre, developer and year, straight from your existing `gamelist.xml`.
- 🎖️ **RetroAchievements** — pops up the moment you unlock one mid-game.
- 📅 **RB Challenge** — Recalbox's own official monthly community Challenge leaderboard.

**Zero configuration on the DMD side.** Install the Recalbox scripts once — **Mode 9** (or the auto-install baked into **Mode 1**) — and each overlay starts working on its own for any game/system that has data to show.

## 🗂️ The raw565 Format in Detail

### 📄 .raw565 (still image from PNG)

```
Size: 128 × 32 × 2 = 8,192 bytes exactly
Format: Raw RGB565 (16 bits per pixel)

ESP32 reading:
  f.read(buffer, 8192);
  drawRGBBitmap(0, 0, buffer, 128, 32);
  // 1 SD operation + 1 draw → 5 ms
```

### 🎞️ .raw565pack + .meta (animated GIF)

```
[Filename].raw565pack           [Filename].meta
├── Frame 0 → 8,192 bytes       ├── delay_0 → 2 bytes (uint16, ms)
├── Frame 1 → 8,192 bytes       ├── delay_1 → 2 bytes
└── ...                         └── ...
```

One SD open + seek per frame, zero on-device GIF decoding.

### ⚡ Bigram Cache — accelerated indexing

`games_cache.bin` indexes each system by 2-letter prefix (703 entries, `#`, `A`, `AA`, `AB`... `ZZ`) — a lookup jumps straight to the right slice instead of scanning a folder of tens of thousands of files.

### 🎭 Mask system

Systems flagged **"L"** (above the configurable file-count threshold, Settings tab — default 5,000) show their cached default image **immediately** while a background task decodes and swaps in the real one. The panel is never left blank.

## 📁 SD Card Structure

```
📁 SD CARD (FAT32)
├── config.ini
├── systems/
│   ├── <system>/
│   │   ├── <game>.raw565            ← still marquee
│   │   ├── <game>.raw565pack        ← animated marquee (frames)
│   │   └── <game>.meta              ← animated marquee (timings)
│   └── _defaults/
│       ├── default.raw565           ← global fallback
│       └── <system>.raw565          ← per-system fallback
├── gifs/                            ← attract-mode playlists (600-GIF pack lands here)
│   ├── Arcade/  Consoles/  Computers/  Pinball_Short/  Pinball_Story/
│   └── Halloween/  XMAS/  Logo/  Other/ ...
├── playlists/
│   └── <playlist_name>.txt
├── games_cache.bin                  ← bigram index
└── systems_cache.dat                ← system index + L/N flags
```

## 🔧 Troubleshooting

For freezes, display corruption, WiFi setup loops, or a DMD that seems to lose sync with Recalbox, see the dedicated **[FAQ & Troubleshooting](FAQ.md)** page on the project's GitHub for the most common causes (USB power, microSD card quality, ESP32 chip revision) — it covers more ground than fits here.

| Problem | Fix |
|---|---|
| "Pillow is not installed" | Auto-installed on first run; if it fails: `pip install Pillow` |
| "GitHub API unreachable" | `_defaults`/600-GIF-pack downloads need an internet connection; retry later (rate-limited) |
| No removable drive detected | Insert/re-check the SD card is visible in Windows Explorer |
| ESP32 shows nothing | Check power (5V 4A min.), `config.ini` at SD root, HUB75 wiring; try Telnet `help` |
| ESP32 not detected (no COM port) | Install USB drivers: CP2102 (Silicon Labs) or CH340/CH341 |
| Slow display / black screen between games | Confirm you ran **Mode 1**; check the system is flagged `L` in `systems_cache.dat`; raise the slow-flag threshold (Settings tab) if your SD card is fast |
| Wrong image shows (box art instead of logo) | Check the **Recalbox version** profile and use **"How to scrape?"**; run **Mode 8** to verify what's actually present |
| Can't set up WiFi during Mode 1 | Optional step — skip it and use the DMD's own first-boot WiFi page instead |
| Connection issues after setting a fixed IP | Make sure you're not **also** using a DHCP reservation for the DMD on your router — use only one of the two methods |

## 📁 Files Generated by the Script

| File | Format | Purpose |
|------|--------|---------|
| `systems/.../*.raw565` | 8,192 bytes RGB565 | Converted PNG (5 ms display) |
| `systems/.../*.raw565pack` | Concatenated frames | Converted animated GIF |
| `systems/.../*.meta` | uint16[] × frame count | GIF frame timings |
| `systems/_defaults/*.raw565` | 8,192 bytes | Per-system fallback images |
| `games_cache.bin` | Bigram index, 703 entries/system | Game cache (accelerated lookup) |
| `systems_cache.dat` | Text | System index + `L`/`N` flags |
| `images_manquantes.txt` | Text | List of missing images (Mode 1/2/3) |
| `reports/mode8_report_*.txt` | Text | Mode 8 report (gamelist ↔ images check) |
| `config.ini` | Text | DMD configuration (WiFi, playlist, brightness...) |
